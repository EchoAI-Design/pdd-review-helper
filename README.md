# 评价巡检助手

用于拼多多商家后台的 Chrome / Edge Manifest V3 扩展。当前版本：**0.4.0**。

## 功能

- 在商家页面左侧显示操作面板，识别当前店铺。
- 默认查询近30天的1、2、3星评价，自动翻页、校验星级和数量、去重并保存进度。
- 记录评价内容、已举报状态及逐条事实和证据核验结果。
- 通过统一按钮批量处理已核验评价，自动定位及填写本条已保存的事实，跳过已举报或举报类型不可用的记录。
- 平台提交由用户手动确认；确认同一评价显示已举报后，队列继续下一条。支持暂停、恢复、手动跳过和结果导出。
- 可导入仅含店铺名称与行号的账号表映射；不需要导入登录账号或密码。

插件不会仅凭评分或评价有无文字推断要挟、同行攻击等原因。填写表单、平台显示已举报与审核通过分别处理，不把打开弹窗计作提交成功。

## 安装

1. 下载仓库源码并解压。
2. 在 Chrome 打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`。
3. 开启开发者模式，点击“加载已解压的扩展”，选择本仓库的 **pdd-review-helper** 文件夹。
4. 打开已经登录的拼多多商家评价管理页面。更新扩展后，点击扩展的“重新加载”并刷新商家页面。

详细使用方法见 [使用说明](pdd-review-helper/使用说明.md)。说明中提到的本地账号表和映射文件不包含在仓库中，需要在使用者自己的电脑上准备。

## 目录

- `pdd-review-helper/`：可直接加载的扩展源码。
- `tests/`：本地模拟页面、领域逻辑、DOM适配和独立浏览器扩展集成测试。

## 测试与限制

0.4.0在开发环境中通过47项模拟测试。测试不操作真实店铺举报，不能替代真实商家页面的适配验证。

开发环境测试命令为 `tests/运行测试.ps1`。脚本使用本机配置的 Node.js / Playwright 路径，浏览器测试使用 Windows Edge；在其他电脑运行前，需要调整这些路径并安装相应依赖。

平台最终提交成功回执、审核结果追踪、原账号表D/E自动回写及自动切店尚未接通。批量队列在结果无法确认时暂停，保留待核对状态。

## 本地数据

评价和任务保存在当前浏览器的扩展存储中，无远程服务或遥测。账号表、店铺行号映射、导出数据、浏览器测试配置目录及旧版安装包均排除在Git提交之外。
